# Bundled typesetting components

Kaster ships these open-source components so cards typeset offline:

- **Typst** compiler (`typst`), Apache License 2.0 — https://github.com/typst/typst
  Includes the Libertinus Serif, New Computer Modern and DejaVu Sans Mono fonts (SIL Open Font License / free licenses).
- **cmarker** 0.1.10 (Markdown → Typst), MIT License — `packages/preview/cmarker/0.1.10/LICENSE`
- **mitex** 0.2.7 (LaTeX math → Typst), Apache License 2.0 — `packages/preview/mitex/0.2.7/LICENSE`

The optional LaTeX engine uses your own Pandoc and TeX installation; it is not bundled.
